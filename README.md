# 🎵 Musician Song Request Platform (ระบบขอเพลงสำหรับนักดนตรีและผู้ฟัง)

> ออกแบบตามตัวอย่างและฟังชั่นของ **[musiciantradethai.com](https://www.musiciantradethai.com/)** (SnowGuin) และระบบดนตรีสดชั้นนำ
> รองรับการใช้งานทั้งบนมือถือของลูกค้า (Mobile Audience Portal), หน้าจอควบคุมของนักดนตรี (Musician Dashboard), และหน้าจอแสดงผลบนเวที / OBS Overlay (Stage View)

---

## ✨ ฟังชั่นหลักตรงตามความต้องการ (Key Features)

### 1. 🔍 ตรวจสอบที่โอนเงินได้จริง (Real Payment & Slip Verification)
- **สร้าง QR PromptPay ตามยอดจริง (Dynamic PromptPay EMVCo Standard):** เมื่อลูกค้าเลือกยอดทิป ระบบจะคำนวณและสร้าง QR Code พร้อมเพย์มาตรฐาน EMVCo พร้อมยอดเงินและเลขบัญชีของวงทันที สามารถเปิดแอปธนาคารใดก็ได้ (K PLUS, SCB EASY, Krungthai NEXT, ttb touch ฯลฯ) สแกนจ่ายได้ทันที
- **สแกน Mini-QR บนสลิปธนาคารอัตโนมัติ:** ใช้ C++ ZXing Engine ถอดรหัส Mini-QR จากรูปสลิปที่ลูกค้าอัปโหลด เพื่อดึงรหัสอ้างอิงธุรกรรม (Transaction Reference / transRef), รหัสธนาคาร (KBank, SCB, KTB, BBL, TTB, BAY, GSB ฯลฯ)
- **ระบบป้องกันการใช้สลิปซ้ำ (Anti-Duplicate / Anti-Replay Attack):** ตรวจสอบว่ารหัสธุรกรรมบนสลิปนี้เคยถูกส่งขอเพลงไปแล้วหรือไม่ หากมีคนนำสลิปเก่าหรือสลิปของคนอื่นมาใช้ ระบบจะตรวจจับและปฏิเสธทันที
- **เชื่อมต่อ Live SlipOK API:** รองรับการเชื่อมต่อกับ SlipOK API (`api.slipok.com`) เพื่อตรวจสอบเงินเข้าบัญชีจริงผ่านเครือข่ายสวิตชิ่งธนาคาร (ITMX) ตรวจสอบชื่อผู้รับ ยอดเงิน และเวลาโอนจริง
- **ระบบตรวจสลิปหน้าเวที (Musician Slip Inspector):** นักดนตรีสามารถคลิกดูรูปสลิปขยายใหญ่ พร้อมข้อมูลธนาคาร, รหัสอ้างอิง, ยอดเงิน และปุ่มอนุมัติด้วยตนเอง (Manual Override) ได้ในคลิกเดียว

---

### 2. 📋 จัดเรียงคิวเพลงที่ขอมาได้ (Dynamic Song Queue Management)
- **โหมดจัดเรียงตามยอดทิป (Tip Priority - ยอดทิปมาก่อน):** เพลงที่มียอดทิปสนับสนุนสูงกว่าจะถูกดันขึ้นสู่อันดับต้นของคิวโดยอัตโนมัติ (หากทิปเท่ากันจะเรียงตามเวลาที่ขอก่อน-หลัง)
- **โหมดจัดเรียงตามเวลาขอ (FIFO / First-Come First-Served):** เรียงคิวตามลำดับเวลาที่ส่งคำขอเพลงเข้ามา
- **โหมดลากจัดเรียงเอง (Manual Drag-and-Drop & Move Up/Down):** นักดนตรีสามารถใช้เมาส์ลากการ์ดเพลงสลับตำแหน่ง หรือกดปุ่มลูกศร ⬆️ ขึ้น / ⬇️ ลง เพื่อจัดระเบียบเพลงเร็ว-เพลงช้าได้ตามฟีลลิ่งของเวที
- **ควบคุมสถานะเพลงบนเวที:**
  - `▶️ เริ่มเล่น (Now Playing)`: ส่งเพลงขึ้นแบนเนอร์เวที พร้อมแสดงข้อความและโต๊ะที่ขอ
  - `✅ เล่นจบแล้ว (Completed)`: ย้ายเพลงลงสู่ประวัติ และสรุปยอดทิปรวม
  - `❌ ปฏิเสธคำขอ (Reject)`: ระบุเหตุผล เช่น วงร้องเพลงนี้ไม่ได้ / เจ็บคอ
  - `⏭️ พักไว้ก่อน (Requeue)`: ย้ายเพลงกลับเข้าคิว
- **เสียงเตือน Audio Chime:** เมื่อมีลูกค้าขอเพลงใหม่เข้ามา ระบบจะส่งเสียงดนตรีเตือนนักดนตรีบนเวทีทันที

## 📱 หน้าจอการใช้งาน 3 รูปแบบ (3 Dedicated Interfaces)

| หน้าจอ | ลิงก์ URL | กลุ่มผู้ใช้ | รายละเอียดการใช้งาน |
|---|---|---|---|
| **หน้าขอเพลงของลูกค้า** | `http://localhost:8000/` | ลูกค้า / ผู้ฟังที่โต๊ะ | ค้นหาเพลงจากคลังของวง, พิมพ์เพลงเอง, ใส่ข้อความฝากแซว/อวยพร, เลือกยอดทิป, สแกนพร้อมเพย์, อัปโหลดสลิป, ตรวจสอบสถานะคิวเพลงของตนเอง |
| **หน้าจอนักดนตรี** | `http://localhost:8000/musician` | นักดนตรี / แอดมินวง | มอนิเตอร์คิวแบบเรียลไทม์, สลับโหมดจัดเรียงคิว, ลากคิวเพลง, ตรวจสลิปโอนเงิน, กดเริ่มเล่น/เล่นจบ, จัดการคลังเพลง, ตั้งค่าวงดนตรี |
| **หน้าจอเวที / OBS** | `http://localhost:8000/stage` | จอทีวีในร้าน / จอเวที / สตรีม OBS | จอขนาดใหญ่แสดงเพลงที่กำลังเล่น (Now Playing), โต๊ะที่ขอ, เพลงถัดไป (Up Next), ยอดทิปรวมคืนนี้, และ QR Code ยักษ์สำหรับให้ลูกค้ายกมือถือสแกนขอเพลง |

## 🚀 วิธีเริ่มต้นใช้งาน (Quick Start)

### วิธีที่ 1: รันผ่าน Windows Script (ง่ายที่สุด)
ดับเบิลคลิกไฟล์:
```
run.bat
```
หรือรันผ่าน PowerShell:
```powershell
.\run.ps1
```

### วิธีที่ 2: รันผ่านคำสั่ง Terminal
```powershell
$env:PATH = "C:\Users\admin\.local\bin;$env:PATH"
uv venv
uv pip install fastapi uvicorn pydantic python-multipart jinja2 httpx pillow qrcode zxing-cpp
.venv\Scripts\python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

## 🧪 การรันแบบทดสอบอัตโนมัติ (Automated Tests)
ทดสอบระบบการสร้าง PromptPay, การตรวจสลิป, การตรวจจับสลิปซ้ำ, และการจัดเรียงคิว:
```powershell
$env:PYTHONPATH = "."
.venv\Scripts\pytest -v tests/test_app.py
```
